# Rotazione durante la riproduzione — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** tasti `r`/`R` che ruotano il video di 90° durante la riproduzione, in entrambe le modalità, più il seek dal vivo in modalità standard.

**Architecture:** una `RotatingSource` (nuovo `rotation.py`) incapsula la sorgente corrente: la cache a 0° in high-performance, altrimenti una `VideoPipeline` avviata con `rotation` e `start_index`. Ruotare o fare seek dal vivo significa fermare la pipeline e avviarne una nuova dal frame giusto. `run_playback` gestisce i tasti, l'overlay di attesa, l'audio e il ridisegno.

**Tech Stack:** Python 3.12, OpenCV (`cv2.rotate`), NumPy, pytest.

**Spec:** `docs/superpowers/specs/2026-10-18-rotation-design.md`

### Task 3: `RotatingSource`

**Files:**
- Modify: `rotation.py`
- Test: `tests/test_rotation.py`

**Interfaces:**
- Consumes: `ROTATIONS` (Task 1); `VideoPipeline.start()`, `.stop()`, `.frame_source()`, `next_frame(timeout=...)` (Task 2); `CachedFrameSource` (`next_frame`, `restart`, `seek`, `__len__`).
- Produces: `RotatingSource(make_pipeline, total, cache=None, start_timeout=15.0)`
  - `make_pipeline(rotation: int, start_index: int) -> VideoPipeline` non ancora avviata.
  - `total: int` frame decimati (≤ 0 = sconosciuto); con `cache`, `len(cache)`.
  - `start() -> None`: senza cache avvia la pipeline a 0° da 0 (senza attendere il primo frame); con cache non fa nulla.
  - `next_frame()`, `restart()` (delega: cache → `restart`; pipeline → no-op), `__len__()` (= `total`), `seek(index)`.
  - `rotate(step: int) -> bool` (`step` = +1/−1).
  - `rotation: int`, `slow_seek: bool` (True quando la sorgente corrente è una pipeline), `close()`.

Regole:
- Ricorda l'indice dell'ultimo frame restituito; la nuova sorgente parte da `ultimo + 1` (0 se nessun frame).
- `rotate`: calcola il nuovo angolo, ferma la pipeline corrente; se nuovo angolo 0 e c'è la cache → `cache.seek(start)`, True. Altrimenti `make_pipeline(angolo, start)`, `start()`, attende il primo frame con `next_frame(timeout=start_timeout)` e lo tiene come prossimo frame. Se il primo frame è None, scade il timeout o c'è un'eccezione: ferma la nuova pipeline, ripristina la sorgente precedente (cache con `seek(start)` oppure `make_pipeline(angolo_precedente, start)` avviata senza attesa), lascia `rotation` invariato, restituisce False.
- `seek(index)`: con la cache attiva → `cache.seek(index)`; con pipeline → ferma e riavvia `make_pipeline(rotation, index)` attendendo il primo frame (se fallisce, `next_frame` restituirà None e la riproduzione termina come per un errore di pipeline). Dopo il seek l'"ultimo indice" è `index - 1`.
- `close()` è idempotente e ferma la pipeline corrente.

- Produces: costanti `ROTATING_TEXT = "Rotazione {}°…"`, `ROTATE_FAILED_TEXT = "Rotazione non riuscita"`, `SEEK_WAIT_TEXT = "Seek…"`.

Comportamento:
- `r` → step +1, `R` → step −1, solo se la sorgente ha `rotate` (altrimenti ignorati).
- Prima di `rotate`: se c'è un ultimo frame, `display.show(ultimo, overlay.lines(ROTATING_TEXT.format(angolo_destinazione)))`; audio `set_paused(True)`.
- Dopo: `display.invalidate()`; `overlay.dirty = True` (il prossimo frame ridisegna l'overlay senza la riga di attesa); se `rotate` restituisce False → `overlay.set_status(ROTATE_FAILED_TEXT, now)`; `clock.rebase(n)`; audio `seek((ultimo_indice + 1) / fps)` (0 se nessun frame) e `set_paused(False)`.
- Seek con `getattr(source, "slow_seek", False)`: prima di `source.seek`, overlay `SEEK_WAIT_TEXT` sull'ultimo frame e audio in pausa; dopo, audio `seek` (già presente) e ripresa, `overlay.dirty = True`, `display.invalidate()` non serve. Seek non lento: invariato.
- Le statistiche FPS non registrano l'intervallo a cavallo di pausa, rotazione o seek lento (generalizzare il reset di `last_draw` oggi fatto solo per `space`).
